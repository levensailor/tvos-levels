# Changelog

Feature history for Band Levels. Each entry is timestamped in America/New_York and uses the
commit message that introduced the feature.

## 2026-10-30 11:02 EDT

- Add the Swift 6 tvOS dashboard so the band can watch gain, VU, dBFS, and LUFS for 13 live tracks across 16 slots on an Apple TV, with selectable metric emphasis, tunable periods, and dimensional-layering artwork.

## 2026-10-30 10:52 EDT

- Add a validated local audio-level bridge so the Apple TV dashboard can receive per-track gain from Logic Pro MCP, VU/dBFS/LUFS from BlackHole, and manual JSON levels through one versioned stream.
